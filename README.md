# hustlen-ai-external-tools

Client-side tools that sit outside the main hustlen.ai web app.

| Tool | Path | Description |
|---|---|---|
| Browser extension | [`browser-extension/`](browser-extension/) | Chromium/Firefox extension. It autofills job applications from the user's Master CV, saves each job applied to as an application, and starts CV + cover-letter tailoring from the job page. |
